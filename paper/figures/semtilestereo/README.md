# SemTileStereo architecture figure

`semtilestereo_architecture.excalidraw` is the primary editable source;
`semtilestereo_architecture_excalidraw.png` is its checked preview. Export
SVG or PDF from Excalidraw after the final manual adjustments. The figure derives its
visual grammar from `experiments/a06_shallow/a08_architecture.excalidraw`.
`semtilestereo_architecture_v2.excalidraw` and its matching PNG are a separate
paper-style revision; the manually edited original has not been overwritten.
The v2 overview replaces experiment IDs and implementation labels with
paper-facing mechanisms, depicts the semantic class-agreement volume, explicit
candidate modulation, tile state, per-scale propagation and upsampling, and the
residual addition. It keeps the class output independent of disparity correction.
There is no separate A09 architecture diagram in the repository. The actual
topology was checked against `experiments/D/D_1_semantic_cost/model.py`,
`experiments/E/E_1_wide2_semantics/model.py`, and
`experiments/B/B_0_fused_baseline/model.py`.

The figure intentionally simplifies YOLO layers 0–17 to a shared frozen
four-scale feature pyramid and two frozen semantic tails. Both rectified views
pass through the same layers 0–6 in a single concatenated batch. The semantic
tails run on both views; only the left logits become the class output. Their
left/right class probabilities form a disparity-candidate agreement volume at
1/16 scale. E3's trainable semantic gate modulates the existing A09 matching
aggregation, before the frozen tile propagation. The trainable class residual
then adjusts the full-resolution disparity using left semantic probabilities
and tile confidence. The semantic output itself is **not** refined by E3.
For the thumbnail, the returned left semantic logits are bilinearly upsampled
to input resolution and then converted to an argmax class map; this is display
post-processing, not a learned output head.
The 38,606 trainable parameters are the E3 gate and residual only; this number
is not the full model size. Lines show tensor dependency, not concurrent GPU
execution: the semantic tails are sequential in `DModel.forward`.

The left/right thumbnails are the paired VKITTI2 **training** images
`Scene18/clone/frames/rgb/Camera_{0,1}/rgb_00259.jpg`, identified in the
seed-42 teacher-aligned full-run manifest. The class and disparity thumbnails
are **genuine inference of E3 step 16,000 on that same pair**, generated by
`paper/figures/semtilestereo_infer_example.py` on an RTX 3050 using the
released VKITTI semantic `best.pt` (renamed locally to
`yolo26m-sem-vkitti2-14class-freeze7-best.pt`). The semantic colors are a
visualization palette. Disparity uses a fixed 0–80 px display range; values
outside it are clipped only for colorization, never for inference.

Reproduce from repository root after retrieving the A09 checkpoint:

```bash
uv run --no-sync modal volume get svde-results \
  /final_pass/a09m_fullsf_a10_v1_20260929/checkpoints/best.pth \
  /tmp/semtilestereo_a09_best.pth
uv run --no-sync python -m paper.figures.semtilestereo_infer_example \
  --stereo /tmp/semtilestereo_a09_best.pth \
  --left paper/figures/semtilestereo/Scene18__clone__00259_left.jpg \
  --right paper/figures/semtilestereo/Scene18__clone__00259_right.jpg \
  --stem Scene18__clone__00259 --display-max 80
uv run --project .agents/skills/excalidraw-diagram/references --no-sync python \
  .agents/skills/excalidraw-diagram/references/render_excalidraw.py \
  paper/figures/semtilestereo/semtilestereo_architecture.excalidraw \
  --output paper/figures/semtilestereo/semtilestereo_architecture_excalidraw.png \
  --width 2700
uv run --project .agents/skills/excalidraw-diagram/references --no-sync python \
  .agents/skills/excalidraw-diagram/references/render_excalidraw.py \
  paper/figures/semtilestereo/semtilestereo_architecture_v2.excalidraw \
  --output paper/figures/semtilestereo/semtilestereo_architecture_v2.png \
  --width 3000
```
