# S2Net: A Multitask Learning Network for Semantic Stereo of Satellite Image Pairs

**Liao et al., IEEE TGRS 2024** · DOI: [10.1109/TGRS.2023.3335997](https://doi.org/10.1109/TGRS.2023.3335997) · **US3D / WHU satellite imagery**.

## Access note

The official record is closed-access and no author-hosted legal manuscript was found. Therefore no PDF or figure is stored locally. This summary is based only on the publisher-indexed abstract; it must be expanded from the paper if the user supplies a lawful copy.

S2Net jointly constructs semantic-supervised cost volumes for disparity and fuses RGB-D features for classification. The indexed abstract reports **2.937% D1-Error** on WHU without target training (previous best 4.297%), US3D mIoU improving **61.375% → 69.096%** with disparity, and **60.76% mIoU** on KITTI semantics.
