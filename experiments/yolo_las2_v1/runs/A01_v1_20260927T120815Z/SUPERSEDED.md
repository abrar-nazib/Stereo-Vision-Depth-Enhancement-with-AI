# Superseded protocol: resized capacity test

The user requires full-image native-resolution inference. This run resized
images to 384x640 without user agreement. It is preserved as an audit record
only, and must not be used as the requested native-resolution comparison.
Its 6.17-pixel original LAS2-S EPE is a resized-subset result, not a validated
claim about native-resolution LAS2 performance. See native_audit_v2 for the
separate full-image baseline audit, with no resizing and FP32 inference.
